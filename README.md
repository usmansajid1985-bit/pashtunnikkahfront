# Pashtun Nikah — public frontend

Next.js site built from `homepage-preview.html`.

## Run

```bash
cd web
npm run dev -- -p 3001
```

Open http://localhost:3001

- Admin stays on http://localhost:3000
- Public site: http://localhost:3001

## Pages so far

- `/` homepage (from preview)
- `/login` basic login UI
- `/signup` placeholder (wizard next)
